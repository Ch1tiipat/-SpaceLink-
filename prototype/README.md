# Prototype (ต้นแบบเดิม)

โฟลเดอร์นี้คือ **ต้นแบบ (prototype) เดิมของ SpaceLink** ที่เขียนด้วย HTML / CSS / JavaScript ล้วน
ไม่มี build step และเก็บข้อมูลไว้ใน `localStorage` เท่านั้น

เก็บไว้เพื่อ **ใช้อ้างอิงการออกแบบและใช้เดโมเท่านั้น**

## วิธีรัน

รันจากภายในโฟลเดอร์ `prototype/`

```bash
python -m http.server 5173
```

แล้วเปิด http://localhost:5173

## ข้อห้าม

- **ห้ามแก้ไขไฟล์ใด ๆ ในโฟลเดอร์นี้** — ถือเป็นสิ่งประดิษฐ์ด้านการออกแบบ (design artifact)
- **ห้ามเชื่อมต่อกับ API** และห้าม import โค้ดจากที่นี่ไปใช้ในระบบจริง
- Frontend ตัวจริงจะถูกสร้างแยกต่างหากที่ `apps/web` (SCRUM-20)
